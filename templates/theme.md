# 默认主题 · 暖纸 / 墨黑 / 金线

三个色值定全局。A-roll 与 B-roll 由 BEATS 的 `bg` 字段自动套用，**不需要手写颜色**。

## 色板

| 令牌 | 色值 | 用途 |
|---|---|---|
| `PAPER` | `#E6D8BC` | A-roll 底（暖纸，带颗粒点阵与暗角） |
| `INK` | `#141310` | B-roll 底（墨黑，带暗角） |
| `GOLD` | `#D9A94A` | 强调（线条 / 高亮 / 关键词） |
| `GOLD_LT` | `#F5D68C` | 金高光（脉冲 / 描边） |
| `CREAM` | `#F3EBD6` | 墨底上的主文字色 |
| `BROWN` | `#3A3226` | 纸底上的主文字色 |

## 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 大标题 / 中文正文 | `Noto Serif SC` / 思源宋体 SemiBold | 印刷质感，主字号 48–170 |
| 数字 / 英文标签 | `MONO`（等宽） | 时间码、编号、英文标签 |

## A-roll / B-roll 语义

- **A-roll（`bg: 'paper'`）**：讲人——人物在场、慢节奏、大留白、单点强调
- **B-roll（`bg: 'ink'`）**：讲理——卡片、图表、对比、流程，节奏更快
- 一句之内可切换（`bg` 决定当句底色，切换有 0.28s 渐变）

## 版式纪律（引擎已内置）

1. 内容带：y 380–1520（上下安全区外）
2. `layoutScale()` 按 box 自动放大（≤1.45），并按画布中线限幅
3. 底部进度尺（`auxRuler`）显示章节 + 全片进度，A/B-roll 都画
4. 数字人位（A-roll）：x 0–560 留空

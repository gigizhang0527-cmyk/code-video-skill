# 动效库 · FredTalk 精选（可自由组合）

> 本库为临时默认来源：从 FredTalk 动效库挑选的可组合基础模板。
> **接口约定**：每条配方 = 触发时机 + 代码片段 + 横→竖适配要点。
> 后续换成自有动效库时，保持此格式与 `beatrender.core.js` 的工具函数即可无缝替换。

> 按语义记法：**入场**(02/04) · **强调**(01/05) · **对比**(03) · **数据**(06)。
> 一次只引 2–3 条配方，做完给静帧验收再进下一条。

底层入场手法（BEATS 的 `mo` 字段）：

| mo | 手法 | 说明 |
|---|---|---|
| 0 | 上推 | 内容从下往上淡入 |
| 1 | 擦除 | 按 box 从左到右 clip 展开 |
| 2 | 缩放 | 从中心/自定义锚点放大 |
| 3 | 劈开 | 画面从中间劈开，两半归位 |
| 4 | 绘制 | 线条/路径生长（描边动画） |
| 5 | 落下 | 从上方落下 + 砸地压扁回弹 |
| 6 | 滑动 | 从右侧滑入 |
| 7 | 原地 | 字幕/内容自身完成动画 |

## 01 · 砸卡（Slam Card）→ `mo: 5` + `drawSlamCard`

**何时用**：一句结论/一个词要"砸"出来（B-roll 高潮、章节收束）。

```js
// vis 里：
const k = clamp((lt - 0.15) / 0.5, 0, 1);            // 0.5s 砸入
if (k > 0) drawSlamCard(g, t, { title: 'B-roll', sub: '墨黑 · 讲理', x: 190, y: 470, w: 700, h: 300, k, style: 'b' });
```

要点：落下曲线用 `eOutBack`/`eElastic` 的压扁（scaleY 0.9→1.04→1）；落地瞬间配 `impact` 音效（声点=落地帧）。
**竖屏适配**：卡片宽度 ≤ 700（两侧各留 190），高度 ≤ 320；上下内容让位，别盖底部进度尺。

---

## 02 · 擦入（Wipe）→ `mo: 1`

**何时用**：一行/一列内容横向铺开（列表、条形对比、字幕块）。

```js
// mo:1 自带 box 裁剪；vis 里做内容自身的生长：
const e = eOutQuart(q); g.fillRect(x, y, W * e, H);
```

要点：内容 **必须完全落在 box 内**（box=clip），否则会被切掉一半。
**竖屏适配**：从"从左到右"改为"从上到下"更符合竖向阅读；扫描条用 4–6px。

---

## 03 · 劈开（Split）→ `mo: 3`

**何时用**：A vs B 对比、前后对比、两种方案的冲突。

```js
// mo:3 整屏劈开；vis 里左右（或上下）两半分别归位
const h1 = eOutQuart(q);
// 左半：x=0..540 下移/右移；右半：x=540..1080 对称
```

**竖屏适配**：竖屏用**上下**劈（上/下两半），横向空间不够分左右。

---

## 04 · 弹入（Pop / Spring）→ `mo: 2` + `springAt`

**何时用**：卡片逐个冒出来（盘点、清单、四宫格）。

```js
const s = 0.86 + 0.14 * springAt(t, c.t0 + 0.05 + i * 0.12, 0.5);   // 每张卡错峰 0.12s
g.translate(cx, cy); g.scale(s, s); g.translate(-cx, -cy);
```

要点：错峰 0.10–0.15s；spring 参数 0.4–0.6 别过冲。
**竖屏适配**：竖屏最多 2 列 × 3 行；卡片 w 320–380、h 180–220。

---

## 05 · 翻卡（Tile Flip · T20p）→ scaleX 翻转

**何时用**：9 宫格/扑克式翻面（"从 A 模板翻到 B 模板"）。

```js
const flip = Math.abs(Math.cos(Math.PI * clamp((t - (c.t0 + 0.30 + (r + col) * 0.225)) / 0.42, 0, 1)));
g.save();
g.translate(cx, cy); g.scale(flip < 0.05 ? 0.05 : flip, 1); g.translate(-cx, -cy);
// 正面 flip<0.5 / 背面 flip>0.5 两套内容
g.restore();
```

要点：翻面瞬间缩小到 0（用 `Math.max(0.04, flip)` 防除零）；错峰按对角线 `(row+col)*0.225`。
**竖屏适配**：3×3 卡阵竖排拉长——行距 200–220，卡 w 268 h 180。

---

## 06 · 生长（Grow / 描边书写）→ `mo: 4` + 路径分步

**何时用**：曲线、进度、描边字（"从零开始"逐笔写）、量表。

```js
// 折线生长：按进度画到第 n 段
const p = clamp((t - c.t0) / 2.2, 0, 1);
for (let i = 1; i <= Math.floor(p * pts.length); i++) g.lineTo(...pts[i]);

// 描边字：clip 从上往下扫
g.beginPath(); g.rect(x - SZ/2, y - SZ*0.82, SZ, SZ*1.02*wq); g.clip();
g.fillText(ch, x, y);
```

要点：曲线用 `wq`/`quintic` 缓动；量表先标刻度过冲再回落（T14f 配方）。
**竖屏适配**：时间轴放底部 1/3（y 1500–1700）；曲线图占中间 40% 高。

## 横屏 → 竖屏适配三原则（FredTalk 移植通用）

1. **重排不缩放**：别把 16:9 整体缩小塞进 9:16；把横排改为竖排、左右改上下。
2. **比例换算用同源系数**：以宽度比（1080/1920=0.5625）缩放元素尺寸，字号至少 28px。
3. **接口保留本义**：圆角/描边/缓动曲线原样保留；只换排布方向与裁切窗口。
